  O Mundo Invertido — A Caçada. 🧟‍♂️

- Sobre o jogo

O Mundo Invertido — A Caçada é um jogo de terror em 3D inspirado no universo de Stranger Things. O objetivo é explorar um labirinto, encontrar os itens necessários, fugir do Demogorgon e escapar pelo portal antes de ser capturado.
O jogo foi desenvolvido como parte de um projeto escolar, utilizando HTML, CSS e JavaScript.

 🎯 Objetivo

- Explorar o labirinto e encontrar os itens.
- Coletar as partes das fitas cassetes.
- Encontrar equipamentos que ajudem durante o jogo.
- Sobreviver ao Demogorgon.
- Encontrar o portal e escapar do Mundo Invertido.

 🎮 Controles

- W, A, S, D: movimentar o personagem.
- Mouse: controlar a visão e mirar.
- Clique esquerdo: atirar.
- E: pegar itens.
- Q: usar kit médico.
- R: recarregar a arma.
- 1 e 2: selecionar equipamentos.

 🛠️ Tecnologias utilizadas

- HTML: estrutura do jogo.
- CSS: aparência da página.
- JavaScript: movimentação, itens, inimigo e regras do jogo.
- Three.js: recursos gráficos e elementos 3D, incluindo a neblina.
- Sketchfab: plataforma utilizada para encontrar o modelo 3D do Demogorgon.
- GLTFLoader: carregamento do modelo 3D do monstro.
- GitHub Pages: publicação do jogo na internet.

 ▶️ Como jogar

1. Acesse o jogo pelo link publicado no GitHub Pages.
2. Inicie a partida.
3. Explore o labirinto e procure os itens.
4. Cuidado com o Demogorgon!
5. Reúna o que for necessário e encontre o portal para escapar.

 👩‍💻 Sobre o projeto

Este jogo foi desenvolvido como atividade escolar para colocar em prática os conhecimentos de programação e criação de jogos. Durante o desenvolvimento, trabalhei com elementos 3D, movimentação, itens, inimigo e ambientação de terror.
